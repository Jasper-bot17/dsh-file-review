# 使用指南

面向日常使用：怎么开面板、怎么改、怎么批注、怎么把意见发回给 AI，以及每种文件格式的边界。

## 1. 打开面板

1. 进入任意 Web GUI 会话（插件作用域是**当前会话的工作区**）。
2. 点会话输入条左侧的「📝 批注」入口，浮层面板叠在会话上方；面板不打断会话，可随时关闭。
3. 面板尺寸会被记住（浏览器 localStorage），下次打开保持上次大小。

面板分三块：

- **左侧文件树**：当前会话工作区内的文件，按目录懒加载；`.bak` 与 `.dsh-file-review/` 运行时目录不展示。
- **中间预览区**：按文件类型渲染（文本 / 页图 / 表格 / 图片 / 媒体）。
- **右侧批注栏**：当前文件的批注列表，可编辑、删除、发送、导出。

## 2. 文本类文件

支持 `.md` `.txt` `.csv` `.json` `.yaml` 与常见代码文件（`.py` `.js` `.ts` `.html` `.css` 等）。

### 编辑与保存

- 直接在预览区改，`Ctrl/Cmd + S` 保存（编辑态也可用工具栏「保存」）。
- 保存前自动生成同名 `.bak`；写回是「临时文件 + 原子替换」，避免写一半坏文件。
- 文件在你编辑期间被外部（AI / 编辑器）改动：保存返回 **409 冲突**，面板提示「内容已更新」，可选择先刷新再合并，不会静默覆盖。
- 关闭面板或切换文件时有未保存改动，会提示。

### 选中批注

1. 在预览区选中一段文字（可跨多行）。
2. 点「批注」或按 `Ctrl/Cmd + Enter`，在气泡里写意见。
3. 批注锚点＝**行号区间**，并记下当时的文件版本；文件后来被改动，旧批注会标 stale，不会假装还指向原文。
4. 右侧批注栏可编辑 / 删除；`Esc` 取消正在编辑的批注。

## 3. Office 与 PDF

### docx / pptx / pdf

- Host 侧本地转成页图（不联网、不上传），每页叠加**透明文字层**：像 txt 一样拖选原文，批注消息带**页码 + 原文摘录**。
- 文字层坐标是归一化的，窗口缩放 100% / 150% / 200% 下选区不跑偏。
- 扫描件、纯图片 PDF 没有文字层：面板提示「本页无文字层」，只能用「＋ 批注本页」整页批注（消息里只有页码与意见）。

### 加载与失败

- 首次打开大文档有 loading 骨架，可取消；取消后不会留下半渲染状态。
- 加密文件、超大文件、转换超时统一错误卡：一句人话 + 「重试」+ 可展开的技术细节；已有批注保留。

## 4. 表格 xlsx

- 用 **DOM 表格**渲染（不是转页图）：行号列标、网格线、列宽、合并单元格、数字右对齐，文字原生可选。
- 批注落到**单元格或区域**：点单元格 → 批注；拖选区域 → 区域批注。
- 冻结窗格：首行 / 首列滚动时保持可见（`sheetView` 冻结信息来自文件本身）。
- 大表默认只渲染前 **1,000 行**，顶部琥珀色截断条写明总行数 / 总列数；点「加载全部」二次确认后继续（上限 20,000 行 / 30 万格）。
- 多工作表时顶部有 sheet 切换；表格转换失败时批注入口置灰，但已有批注不会丢。

## 5. 图片

`png` `jpg` `jpeg` `gif` `webp` `bmp` 原图预览，只能整图批注。消息格式为 `图片 【意见】…`，不带页号 / 行号。`avif` / `ico` 同样原图预览；`tiff` / `heic` 浏览器不认，走错误卡提示转 PNG。

## 6. 视频与音频（v0.3.0）

- 视频：`mp4` `m4v` `webm` `ogv` `mov`（H.264）；音频：`mp3` `wav` `m4a` `aac` `flac` `ogg` `oga` `opus`。原生播放器（播放 / 暂停 / 拖动进度条 / 倍速 / 音量），切换标签不打断其他文件。
- Host 走 HTTP Range（`200` 全量、`206` 分段、`416` 越界，补 `HEAD`）：拖动进度条只为需要的片段发请求，不会把整个文件读进内存；单文件上限 **4 GB**。
- **时间码批注**：先拖到要说的位置，点工具栏「＋ 批注视频 00:42」（音频同理），批注带 `at` 秒数；点批注卡会 seek 回该秒并播放。消息格式：

  ```text
  1. 视频 00:42 【意见】这段口播太赶，放慢一点。
  ```

  不带【原文】、不出现 `L0-0`。
- 浏览器放不了的编码：H.264 的 `mov` 能播；HEVC 编码、非 H.264 `mov` 由看门狗兜底（`loadedmetadata` 后 `videoWidth` 为 0，或 2.5 s 内没有元数据即判不支持）出错误卡，不会黑屏。`tiff` / `heic` 走 415 `UNSUPPORTED_PREVIEW` 专属「这个格式暂不支持预览 / 转成 PNG」卡。错误态批注入口置灰。

## 7. 发给 AI

1. 点批注栏「发给 AI」。
2. 弹出确认框：显示将要发送的结构化消息（文件路径、版本、每条批注的位置、原文摘录、意见），可勾选、可改。
3. `Ctrl/Cmd + Enter` 或点「发送」：消息进入当前会话（等价于你自己发的一条消息），AI 按批注修改。
4. 发送失败时面板提示原因，并保留「复制到剪贴板」兜底。

消息示例：

```text
请按以下批注修改文件：

文件：outputs/2026Q3-市场简报.md（v3）
共 2 条批注

1. L3-3 【原文】"月活达到 4.2 亿"
   【意见】数据口径是什么？请标来源和统计时间。

2. L8-8 【原文】"整体来看，市场仍处于较快增长通道"
   【意见】改成 3 条可执行建议，每条带负责人和时间点。

要求：只改批注涉及的内容，其余保持不变；改完告诉我改了哪几处。
```

## 8. 批注持久化与多文件

- 批注改动会自动写入当前会话工作区 `.dsh-file-review/`，**重开面板或刷新页面后自动还原**；存储缺失时从空批注开始，损坏时按空批注处理，不会白屏。
- 上限：单文件 **512 KB / 500 条批注**；同一文件多处同时写入会按批注 id 合并，不会互相覆盖，也不会因为「版本冲突」要求你重做。
- 一次最多打开 **8 个文件**（标签），超出提示先关一个；标签可切换、关闭，右键（或标签上的 ×）关闭。
- 导出：批注栏「导出」生成 `.annotations.md`（当前文件全部批注的 Markdown 汇总），可归档或贴进 issue。

## 9. 外部修改提示

AI 在会话里改了文件，或你用其他编辑器改了同一文件：

- 面板检测到变化后提示「内容已更新」，点「刷新」看新内容；
- 当前有未保存编辑时先提示冲突，选择「放弃本地改动并刷新」或「保留本地改动」；
- 行级 diff 高亮在 0.4.0 提供，当前只提示变化并提供刷新。

## 10. 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl/Cmd + S` | 保存当前文件 |
| `Ctrl/Cmd + Enter` | 发送批注（确认框内） |
| `Esc` | 关闭面板 / 取消编辑 |

## 11. 边界速查

| 场景 | 行为 |
|---|---|
| 工作区外的路径 | 拒绝（403），不会读工作区外文件 |
| 盘根当工作区 / 路径含 `..` | 拒绝（403 / 400） |
| 与其他写入并发 | 文件保存版本不符 → 409 不覆盖；批注写入按批注 id 合并，不会因并发冲突 |
| 扫描件 / 无文字层 | 整页批注兜底 |
| 超大表 | 先渲 1,000 行，可手动加载全部 |
| 媒体编码浏览器不支持（`mov` / HEVC） | 错误卡 + 转码建议，不黑屏 |
| 媒体文件 > 4 GB | 直接拒绝并提示上限 |
| `tiff` / `heic` 图片 | 错误卡提示转 PNG |
| 批注存储 | 工作区 `.dsh-file-review/`，建议 gitignore |
